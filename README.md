# Customer Behavior Analysis

## Overview

This Data Analytics project focuses on analyzing customer behavior to uncover valuable business insights. The project involves data loading, cleaning, exploratory data analysis (EDA), SQL-based analysis, and dashboard creation to understand customer purchasing patterns and support data-driven decision-making.

## Dataset

The dataset contains customer-related information such as demographics, purchase history, spending behavior, and transaction details. It is used to identify trends, customer segments, and key business opportunities.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* PostgreSQL
* Power BI
* Jupyter Notebook

## Project Steps

### 1. Data Loading

* Imported the dataset using Python.
* Examined data structure, data types, and summary statistics.

### 2. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected inconsistent data formats.
* Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)

* Analyzed customer demographics and purchasing behavior.
* Identified trends, patterns, and correlations.
* Created visualizations for better understanding.

### 4. SQL Analysis

* Loaded cleaned data into PostgreSQL.
* Wrote SQL queries to extract business insights.
* Performed aggregations, filtering, joins, and trend analysis.

### 5. Power BI Dashboard

* Built interactive dashboards.
* Visualized KPIs, customer segments, sales trends, and business performance metrics.
* Enabled easy exploration of insights through dynamic reports.

## Dashboard Highlights

## Dashboard Highlights

## Results

The project provided actionable insights into customer behavior, helping identify purchasing trends, high-value customers, and opportunities for improving marketing strategies and customer engagement.

## How to Run

1. Clone the repository.
2. Install required Python libraries.
3. Load the dataset into the project directory.
4. Run the Python notebooks/scripts for data cleaning and EDA.
5. Import the cleaned dataset into PostgreSQL and execute SQL queries.
6. Open the Power BI file to explore the interactive dashboard.
